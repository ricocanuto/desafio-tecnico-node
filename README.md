# Desafio Técnico - Node.js

Resolução de desafios técnicos focados em lógica de programação e manipulação de estruturas de dados utilizando JavaScript / Node.js.

## 🚀 Funcionalidades
1. **Cálculo de Comissões:** Processamento de relatórios de vendas com faixas de comissão (1% e 5%).
2. **Gerenciamento de Estoque:** Controle de entradas/saídas com geração de ID único (`UUID`) por movimentação.
3. **Cálculo de Juros Diários:** Cálculo de parcelas em atraso com taxa fixa diária de 2,5%.
